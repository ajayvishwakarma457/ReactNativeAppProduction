# React Native Reanimated v3 Animations Guide

React Native Reanimated v3 runs animations directly on the native UI thread, bypassing the React Native JSON Bridge entirely. This guide details how to implement animations using Shared Values, Animated Styles, worklets, and layout triggers.

---

## 1. Core Architecture Concepts

* **Shared Values (`useSharedValue`)**: The source of truth for animated data. They hold references to numeric or string values residing directly in UI thread memory.
* **Animated Styles (`useAnimatedStyle`)**: Maps Shared Values directly to view layout styles. When a Shared Value changes, Reanimated computes and renders the changes on the native UI thread.
* **Worklets**: High-performance C++ wrapped JavaScript functions that run synchronously on the UI thread. Marked with `'worklet'` at the top (autogenerated by the Babel plugin).

## 2. Basic Scale & Opacity Animation Example

We have added a live interactive animation demo inside the Hooks Playground page ([HooksPlaygroundScreen.tsx](file:///Users/ajay/Documents/ReactNativeAppProduction/apps/app/src/hooksPlayground/screens/HooksPlaygroundScreen.tsx)).

Here is the implementation:

```typescript
import React from 'react';
import { TouchableOpacity, Text } from 'react-native';
import Animated, { useSharedValue, useAnimatedStyle, withSpring, withTiming } from 'react-native-reanimated';

export const AnimatedCard = () => {
  // 1. Declare Shared Values
  const scale = useSharedValue(1);
  const opacity = useSharedValue(1);

  // 2. Map values to styles
  const animatedStyle = useAnimatedStyle(() => {
    return {
      transform: [{ scale: scale.value }],
      opacity: opacity.value,
    };
  });

  // 3. Trigger timing and spring physics
  const handlePressIn = () => {
    scale.value = withSpring(0.9); // Physics-based spring scale down
    opacity.value = withTiming(0.8, { duration: 150 }); // Linear timing opacity
  };

  const handlePressOut = () => {
    scale.value = withSpring(1);
    opacity.value = withTiming(1, { duration: 150 });
  };

  return (
    <Animated.View style={[styles.card, animatedStyle]}>
      <TouchableOpacity 
        activeOpacity={1}
        onPressIn={handlePressIn}
        onPressOut={handlePressOut}
      >
        <Text>Press to Scale</Text>
      </TouchableOpacity>
    </Animated.View>
  );
};
```

## 3. Layout Animations (Entering & Exiting)

Reanimated v3 makes it incredibly simple to animate components when they mount or unmount from the UI layout using entering/exiting property handlers:

```typescript
import Animated, { FadeIn, FadeOut } from 'react-native-reanimated';

export const ListElement = () => {
  return (
    <Animated.View 
      entering={FadeIn.duration(300)} 
      exiting={FadeOut.duration(200)}
    >
      <Text>I fade in when mounted, and fade out when unmounted!</Text>
    </Animated.View>
  );
};
```

## 4. Best Practices for High Performance

1. **Avoid Stalling the UI thread**: Never execute expensive JS calculations (like large loops or Redux updates) inside your `useAnimatedStyle` callbacks. Keep those blocks pure and computational only for style values.
2. **Utilize `useDerivedValue`**: For value calculations derived from other shared values, use `useDerivedValue` to avoid bridge context syncs.
3. **Bridge Calls (`runOnJS`)**: If you need to trigger a JS state update at the end of an animation, wrap the call in `runOnJS`:
   ```typescript
   import { runOnJS } from 'react-native-reanimated';

   const onAnimationEnd = () => {
     console.log("Animation complete on JS thread");
   };

   // Inside gesture handler or worklet
   runOnJS(onAnimationEnd)();
   ```
